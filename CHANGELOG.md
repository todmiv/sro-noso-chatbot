# Журнал изменений (Changelog)

Все заметные изменения в этом проекте будут документированы в этом файле.

Формат журнала основан на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-19

### Добавлено
- **Основная функциональность бота:**
  - Команды: `/start`, `/help`, `/profile`, `/documents`, `/consultation`, `/membership`
  - Система управления профилями пользователей с организацией
  - Интеграция с ИИ DeepSeek для консультаций
  - Поиск и скачивание документов СРО
  - Проверка членства в реестрах НОСТРОЙ/НОПРИЗ

- **Архитектура:**
  - Модульная структура с разделением на сервисы
  - Асинхронная обработка на базе FastAPI + Aiogram 3
  - PostgreSQL база данных с SQLAlchemy ORM
  - Redis для кеширования
  - Векторный поиск с FAISS и RAG-системой

- **AI-интеграция:**
  - Поддержка DeepSeek API с нативным SDK
  - Система эмбеддингов для семантического поиска
  - Автоматическая обработка документов PDF/DOCX

- **Мониторинг и DevOps:**
  - Метрики Prometheus
  - Health checks для всех сервисов
  - Docker Compose для разработки и продакшена
  - CI/CD pipeline с тестами и безопасностью
  - Graceful shutdown и обработка сигналов

- **Безопасность:**
  - JWT аутентификация
  - Валидация данных с Pydantic
  - Шифрование чувствительных данных
  - Сканирование уязвимостей Trivy

### Исправлено
- Корректная обработка команды `/profile` с полем `organization_name`
- Импорт UserService из правильного модуля
- Обработка ошибок в AI-интеграции

### Тестирование
- Набор unit-тестов с pytest
- Интеграционные тесты для основных функций
- Тестирование покрытия кода
- Автоматические тесты в CI/CD

### Документация
- Подробный README с описанием функциональности
- Руководство по установке и настройке
- API документация для основных эндпоинтов

## Руководство по внесению изменений

### Типы изменений
- `Added` для новых функций
- `Changed` для изменений в существующем функционале
- `Deprecated` для функций, которые будут удалены в будущем
- `Removed` для удаленных функций
- `Fixed` для исправлений багов
- `Security` для исправлений уязвимостей

### Формат записей
- Используйте прошедшее время: "Добавлена функция X", не "Добавляем функцию X"
- Будьте конкретны и описывайте влияние на пользователей
- Группируйте похожие изменения
- Указывайте ссылки на issues/PR, если применимо

### Примеры
```
### Добавлено
- Поддержка поиска документов по ключевым словам
- Кеширование результатов AI-запросов в Redis

### Исправлено
- Ошибка при обработке пустых ответов от DeepSeek API
- Некорректное отображение имен файлов в списке документов
```
